Ordinary R CMD check --as-cran compiler-flag regression

R version: 4.6.2, Linux x86-64
The R installation was a private copy with the leaf-frame flag added to its
actual Makeconf defaults. No live R installation or user profile was changed.
A private check profile was selected through R_CHECK_ENVIRON. Remote CRAN
incoming feasibility was disabled for this deliberately unsubmitted fixture;
compilation checks, clock checks, timestamp checks and manual generation ran.

package-added -Wconversion. After one explicit repair of the selected profile,
the same archive still reports the -Wconversion NOTE and Makevars WARNING,
but no inherited leaf-frame NOTE. Both compiler command lines are byte-identical.
