Inherited-build validation configuration

The interpreter and libR are byte-identical copies of the installed Debian
R 4.6.2 runtime. The copy's bin/R path points to the private copy. Its Makeconf
adds only -mno-omit-leaf-frame-pointer to the C compiler default flag variables,
simulating Ubuntu's inherited compilation setting. No live R installation,
source-package compiler override, global profile or user check profile was edited.

The explicit one-time repair was applied to a private selected check profile.
That profile appends only the verified inherited known flag and enables
compilation-flag checking. It contains no clock, timestamp or incoming-check
setting. The subsequent command is ordinary R CMD check --as-cran; it does not
run through prismrepl-check.R or the independent UTC/check-profile driver.
